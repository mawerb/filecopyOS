# Filecopy (CECS 326)

A C program that copies a file using a pipe between a parent and child process.

## Compile

```bash
gcc filecopy.c -o filecopy
```

## Usage

```bash
./filecopy <input> <output>
```

## Example

```bash
./filecopy input.txt copy.txt
```
